# 生日快乐

一个可以亲手过完的生日小游戏。你在十月十六醒来，选一条路，再亲手把这个生日做完。每条路都是温暖的好结果。

线上地址：[https://maclalex.github.io/birthday/](https://maclalex.github.io/birthday/)

## 怎么玩

三条开始的路：

- 点蜡烛：一支支点亮，按住吹灭，然后许愿或唱生日歌。
- 准备蛋糕：打开、看字、插蜡烛、切第一角，再决定自己吃还是等人一起切。
- 拆祝福：打开三封生日快乐，再决定请大家来，或一封封回过去。

六种生日会收进相册，存在这台设备上。集满需要多过几次。右上角可以开关背景音乐。

## 本地运行

```bash
npm install
npm run dev
```
