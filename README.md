# 生日快乐

一个可以亲手过完的生日小游戏。十月十六从清晨玩到夜里：点蜡烛、许愿、唱生日歌、准备蛋糕、拆祝福，再决定这一岁要怎么被庆祝。每条路都是温暖的好结果。

线上地址：[https://maclalex.github.io/birthday/](https://maclalex.github.io/birthday/)

## 怎么玩

第一次点击后会循环播放生日小夜曲。页面上方可以换成八音盒或海边微风，右上角可以关掉。

三条开始的路都会再走几幕：

- 蜡烛：点亮、吹灭、许愿或唱歌，然后出门、见面，或把歌分给某个人。
- 蛋糕：亲手准备好，再去配花，或在家里把桌子空出来，晚上可以自己吃，也可以等人一起切。
- 祝福：拆开三封信，回给其中一个人，或把大家约到夜里一起吹蜡烛。

十种生日会收进这台设备的相册。集满需要多过几次。

```bash
npm run dev
```
