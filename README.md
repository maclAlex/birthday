# 生日快乐

一个很短的重生小游戏。你在十月十六的生日清晨醒来，每次选择都是一种过生日的方式。每条路都会把生日快乐送到你面前。

线上地址：[https://maclalex.github.io/birthday/](https://maclalex.github.io/birthday/)

## 怎么玩

从点蜡烛、取蛋糕，或告诉别人今天是你的生日开始。不同选择会走进不同的生日情景：自己许愿、唱生日歌、一个人切蛋糕、和大家一起吹蜡烛、把花送给第一个祝福你的人、写一张生日卡片。

走到结局后，可以再过一次这个生日。右上角可以开关背景音乐。

## 本地运行

```bash
npm install
npm run dev
```

## 发布

推送到 `main` 后，GitHub Actions 会发布到 GitHub Pages。
