# 再活一次今天

一个很短的重生小游戏。你在十月十六醒来，每次选择都会走进不同的情景。每条路都是好结果。

线上地址：[https://maclalex.github.io/birthday/](https://maclalex.github.io/birthday/)

## 怎么玩

从清晨开始，选一条路。走到结局后，可以再活一次今天，换另一条。

一共十个好日子：热汤面、自己的歌、把花送出去、把花带回家、走到水边、坐完一程车、见面、把话留在对话框里、书店里的一页、走完一圈。

右上角可以开关背景音乐。

## 本地运行

```bash
npm install
npm run dev
```

## 发布

推送到 `main` 后，GitHub Actions 会发布到 GitHub Pages。
